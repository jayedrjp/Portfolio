A modern, responsive personal portfolio website showcasing my projects, skills, and contact information. Built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

> 🔗 **Live Site:** https://jayedrjp.vercel.app/

---

## ✨ Features

- Fully responsive design for all screen sizes
- Smooth scrolling and animated sections
- Project showcase with tech stack details
- Contact section with direct links
- Clean dark-themed UI with glassmorphism cards

## 🛠️ Tech Stack

HTML5 · CSS3 · Vanilla JavaScript · Font Awesome 6

## 🚀 Run Locally

```bash
git clone https://github.com/jayedrjp/portfolio.git
cd portfolio
# Open index.html in your browser — no build step needed
```
